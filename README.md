Metro AutoConnect

Android application for connecting to MT_FREE public Wi-Fi.

Features

- Wi-Fi connection assistance
- Captive portal detection
- Quick access to Android Wi-Fi authentication
- Russian and English interface
- Android 10–16 support

Installation

1. Open the repository's Actions tab.
2. Select a successful Android build.
3. Download the APK artifact.
4. Extract the APK and install it on Android.

Status

Experimental version 1.3. Automatic authentication is not guaranteed. Provider verification and advertising requirements remain in place.
